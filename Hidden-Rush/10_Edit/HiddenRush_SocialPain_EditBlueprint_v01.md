# Hidden Rush — Editing Blueprint

**Video:** *Being Ignored Isn't Emotional. It's Physical.* · v01
For Premiere / DaVinci Resolve / Final Cut / CapCut / AI-edit workflows. Aesthetic: **premium and
restrained** — no template transitions, no karaoke captions, no zoom-spam.

## Editing rules
- **B-roll cadence:** never let a static frame exceed ~7s except the two designed silence beats
  (empty chair 1:05, midpoint 6:05). Add a subtle 3–5% slow push or parallax on otherwise-still
  AI stills so nothing feels dead.
- **Parallax:** separate AI stills into 2–3 depth layers (subject / mid / bg) for 2.5D drift on the
  ridge (S16), fire circle (S17), climax room (S32).
- **Speed ramps:** only in the modern-escalation montage (S20) — quick in, hard out on each clip to
  the tick track. Nowhere else.
- **The red accent is sacred:** grade so red appears ONLY on alarm/pain beats (S4, S21, S26) and
  cools out (S28, S32). If a stock/AI clip has stray warm reds, desaturate them.
- **Match cuts:** burned-hand ↔ excluded-figure (S15); cold phone (S1) ↔ warm phone at climax (S32)
  — same framing, opposite light. These callbacks are the spine; protect them in the edit.

## Motion graphics / typography
- Kinetic type only 3 places: title (0:33), "just ignore it" glitch (5:50), "you were never too
  sensitive" (9:40). Sora-esque restraint — one idea per card.
- Brain node, Cyberball, venn, wiring-merge = build in AE/Resolve Fusion, not generative video.
- Lower-third for the one term ("dorsal anterior cingulate cortex") appears ~1.5s, then gone.

## Subtitles / captions (burned-in, mobile-first)
- Max **two short lines**, ≤ ~7 words/line, centered lower-third, safe margins (10% inset).
- Clean sans (e.g. **Sora** / Inter Semibold), ivory on 40% dark scrim or soft shadow.
- **Highlight only the emphasis words** (from VO notes: *physical, borrowed, false alarm, fewer hurt
  feelings, not a flaw, name*) in the red accent — one or two per screen max. **No** word-by-word
  karaoke.
- Time captions to the *pause map*; let silence beats stay caption-free.

## Color grade
- Base: crushed blacks, cool shadows, desaturated overall, filmic contrast (subtle S-curve).
- Cold sections (open, modern, midpoint) push teal-blue; warm beats (fire, climax) lift amber in
  highlights only. Fine grain overlay + very subtle vignette throughout for cohesion.

## Retention-driven edit decisions
- Front-load: the title sting lands at 0:33, AFTER the hook has already created tension (never brand
  first). Secondary "unpromised reveal" (the Tylenol tease can be flashed for 0.5s at ~0:40 as a
  pre-echo). 
- Pattern interrupt every 20–40s is baked into the scene table; verify none is missed in assembly.
- Open the export with the strongest 3s (phone + read receipt) — this is the scroll-stopper.
- End screen: hold the last dark frame 3s with the "next video" (video 2 tease) card so the session
  chains.
