# KIcasso Design System

> Visuelle Identität: **Neon-Graffiti / Street-Art** (Rebrand zu KIcasso, 2026-06-16)
> Frühere Quelle (Business-Positionierung): Kordix_AI_Brand_Guide.md (Google Drive, 05.06.2026)

## Brand

- **Name:** KIcasso  (KI + Picasso)
- **Tagline:** Intelligence. Compliance. Impact.
- **Positioning:** AI-Powered Solutions for Pharma & Healthcare Excellence
- **Visueller Charakter:** mutig, kreativ, energetisch — Neon-Graffiti auf dunkler, rissiger Wand. Der Auftritt ist auffällig und verspielt, während die inhaltliche Tonalität (Pharma/GMP) fachlich und seriös bleibt.

## Color Palette

Signature Look: **Neon-Graffiti** — leuchtende Neonröhren-Akzente mit Glow, Farbspritzern und tropfender Farbe (Drip) auf tiefer, dunkler Betonwand.

| Role | Hex | Usage |
|------|-----|-------|
| Neon Cyan | `#38E5FF` | **Primär-Akzent** — Outline/Maskottchen, „KI", Glow |
| Hot Pink / Magenta | `#FF2D9C` | **Sekundär-Akzent** — „casso", Highlights, Drip |
| Neon Lime | `#A6FF3C` | **Tertiär-Akzent** — Mund-Element, Spritzer, Status „live" |
| Electric Blue | `#0078FF` | Buttons/Links (Übergang aus dem alten System) |
| Background Navy | `#070B1E` | Haupt-Hintergrund |
| Wall Charcoal | `#12101C` | Textur-/Sektions-Hintergrund (rissige Wand) |
| Surface | `#0E1430` | Karten / Flächen |
| White | `#FFFFFF` | Text auf Dunkel |

**Neon-Glow (Beispiel):** Text/Outline-Farbe + `text-shadow`/`box-shadow` in derselben Farbe (z. B. `0 0 7px #38E5FF, 0 0 18px rgba(56,229,255,0.6)`).

## Typography

- **Primary Font (UI):** Sora (Google Fonts, modern-geometrisch)
- **Wortmarke:** Neonröhren-/Graffiti-Stil (keine reine Schriftart — als Logo/Asset, siehe unten)
- **Fallback:** Segoe UI → Arial

## Logo

- **Maskottchen (Bildmarke):** Neon-Cyborg-Kopf — Cyan-Outline, Antenne mit pinkem Punkt, seitliche Kopfhörer/Ohren, ein Auge als pink-roter Neon-Ring, das andere als Kamera-Blende (Aperture/Iris), wackeliger neon-grüner Mund, tropfende Neonfarbe (Cyan/Pink/Grün). Auf dunkler, rissiger Wand mit Farbspritzern.
- **Wortmarke:** „KI" (Neon-Cyan) + „casso" (Neon-Pink/Magenta), Graffiti-Drip-Stil, optional pinker Unterstrich-Swoosh.
- **Varianten:** rundes Icon-Badge (nur Maskottchen) · horizontale Lockup (Maskottchen + Wortmarke).
- **Asset-Dateien:** noch ins Repo aufnehmen unter `public/brand/` (PNG/SVG) — in der App ist die Wortmarke aktuell per Neon-CSS nachgebaut, das eigentliche Maskottchen-Logo wird eingebunden, sobald die Dateien vorliegen.
